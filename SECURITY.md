# Security / abuse inquiries

This project is a self-hosted gateway for LLM request handling. It ships no
attack payloads, no target infrastructure, and no operational content.

If you have concerns about potential misuse:

- Please open an issue on this repository describing the concern.
- For private matters, open an issue titled `confidential` and we'll follow up
  without public discussion.

We respond to good-faith reports and will work to resolve concerns directly.
